# 용사후보 · 사냥꾼 스킬 아이콘

2026-09-04 검토: 총 40종(각 20종), 수정 33종, 유지 7종.

- 일반·비범·마법: 캐릭터 없이 무기·사물·효과로 표현합니다. 사용자 지정 예외로 전투의 함성·수호의 오라는 인물 중심입니다.
- 서사·전설·이계: 해당 캐릭터가 아이콘에 보이도록 표현합니다.
- 용사후보는 기존 금발·갑옷, 사냥꾼은 짙은 수염·갈색 장비의 일러스트 외형을 참조했습니다.
- 개별 아이콘 파일은 `final/`, 원본 비교용 사본은 `before/`에 있습니다.
- `index.html`을 열면 전체 전후 비교와 수정본만 보기 기능을 사용할 수 있습니다.
- `review.json`은 등급·원본·최종 파일·수정 이유, `prompts.json`은 수정 33종의 최종 생성 프롬프트입니다.
- 내장 이미지 생성 도구(image_gen)로 아이콘마다 별도로 생성했습니다. 초기 폐기 시안은 포함하지 않았습니다.
- 기존 앱 리소스는 보존했습니다. 이 묶음은 검토용 이미지이며 앱 리소스 연결은 변경하지 않았습니다.

유지: 용사후보 1종(정의의 심판), 사냥꾼 6종(궁술, 속사, 방어, 독액주입, 처형 사격, 관절 사격).


최신 v3 수정: 전투의 함성은 직접 외치는 인물, 수호의 오라는 인물 중심 오라, 구원의 맹세는 갑옷 십자가 장식 제거. 내장 image_gen 사용, 상세 프롬프트는 targeted-edits-v3-prompts.json에 있습니다.


최신 v4 수정: 용사 검법은 용자검법 1초식의 플루크형 원근 구도, 구원의 맹세는 눈을 감은 맹세 자세, 극독의 저주는 화살을 겨누지 않는 손 시전 구도. 내장 image_gen 사용, 상세 프롬프트는 targeted-edits-v4-prompts.json에 있습니다.


최신 v5 수정: 용사 검법 캐릭터 비중을 줄이고 검날 길이와 강제 원근을 크게 과장. 상세 프롬프트는 targeted-edits-v5-prompts.json에 있습니다.


최신 v6 수정: v5의 과장된 검 구도를 유지하고 모든 형태를 굵은 저해상도 도트 클러스터로 재작업. 상세 프롬프트는 targeted-edits-v6-prompts.json에 있습니다.
